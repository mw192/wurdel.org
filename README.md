# wurdel.org

Personal profile website for Dr. Maik Wurdel — Technology Leader, Data Platform, Data as a Product, Digital Twin & Agentic Engineering.

## Overview

A single self-contained `index.html` with no external dependencies. All styles are inline and the profile photo is embedded as Base64.

## Deployment

Hosted via [GitHub Pages](https://pages.github.com/). To enable:

1. Go to **Settings → Pages**
2. Set source to **Branch: main / root**
3. Save — the site will be live at [wurdel.org](https://wurdel.org)

## Structure

```
index.html   # Complete website — single file, no build step required
```
